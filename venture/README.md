## Operating rules

1. **Everything real.** Real products, honest copy, real store. Nothing that "looks legit" —
   only things that are legit. Payment processors freeze payouts of anything else.
2. **No credentials in this repo — ever.** No passwords, API keys, tokens, or payout details.
   This folder holds documentation and build artifacts only. Keep passwords in a password
   manager on your side.
3. **£0 infrastructure until revenue.** Free subdomains (GitHub Pages / Netlify / Vercel),
   free storefront (Gumroad), free organic traffic. Paid domains (~£10/yr) only after a
   product proves itself.
4. **Human-posted marketing only.** Claude writes the content; a human posts it. No
   automated cross-posting — platforms ban it and blacklist the links.
